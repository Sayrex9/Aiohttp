# Домашнее задание к лекции «Aiohttp»

## Описание проекта
В рамках данного задания сервис объявлений (REST API), ранее написанный на Flask, был переписан с использованием асинхронного фреймворка **aiohttp**.

## Особенности реализации
- Использованы асинхронные обработчики (`async def`) для неблокирующей обработки запросов.
- Чтение тела запроса реализовано через `await request.json()`.
- Маршрутизация настроена через `app.router.add_*` (вместо декораторов во Flask).
- Для возврата ответов используется `web.json_response`.
- Хранение данных реализовано в памяти (в словарях Python) в рамках учебного задания.

## Реализованный функционал
- **POST `/register`** — регистрация пользователя (почта и хэш пароля).
- **POST `/login`** — авторизация и получение токена.
- **POST `/advertisements`** — создание объявления (требуется токен).
- **GET `/advertisements/{ad_id}`** — получение объявления по ID.
- **DELETE `/advertisements/{ad_id}`** — удаление объявления (требуется токен владельца).

## Стек технологий
- Python 3
- aiohttp

## Как запустить проект локально

1. Установите зависимости (если файла requirements.txt нет, установите вручную):
   ```bash
   pip install aiohttp
   ```

2. Запустите сервер:
   ```bash
   python server.py
   ```

3. Сервер будет доступен по адресу `http://127.0.0.1:8080/`.
