# Домашнее задание к лекции «Aiohttp»

## Описание проекта
В рамках данного задания сервис объявлений (REST API), ранее написанный на Flask, был переписан с использованием асинхронного фреймворка **aiohttp**. 
Проект был доработан в соответствии с замечаниями преподавателя: данные теперь хранятся в базе данных, добавлены недостающие методы и внедрена безопасная авторизация.

## Особенности реализации и исправленные замечания
1.  **Хранение данных (aiosqlite):** Данные больше не хранятся в памяти. Реализована асинхронная база данных SQLite. Таблицы `users` и `advertisements` создаются при старте приложения (`on_startup`), все операции выполняются через `await`.
2.  **Безопасность (JWT):** Авторизация переведена с небезопасного MD5 на **JWT-токены** (библиотека `PyJWT`). Токен генерируется при логине и имеет время жизни (1 час).
3.  **Недостающие эндпоинты:** 
    *   Добавлен **GET `/advertisements`** для получения списка всех объявлений.
    *   Добавлен **PATCH `/advertisements/{ad_id}`** для редактирования объявления.
4.  **Проверка прав:** Редактировать и удалять объявления может только их автор (владелец). Проверка реализована через `JOIN` таблиц в базе данных.

## Реализованный функционал
- **POST `/register`** — регистрация пользователя (почта и хэш пароля).
- **POST `/login`** — авторизация и получение JWT-токена.
- **POST `/advertisements`** — создание объявления (требуется токен).
- **GET `/advertisements`** — получение списка всех объявлений.
- **GET `/advertisements/{ad_id}`** — получение объявления по ID.
- **PATCH `/advertisements/{ad_id}`** — редактирование (требуется токен владельца).
- **DELETE `/advertisements/{ad_id}`** — удаление (требуется токен владельца).

## Стек технологий
- Python 3
- aiohttp (асинхронный веб-фреймворк)
- aiosqlite (асинхронная работа с БД SQLite)
- PyJWT (генерация и проверка токенов)
- hashlib (хеширование паролей)

## Как запустить проект локально

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите сервер:

   ```bash
   python server.py
   ```

3. Сервер будет доступен по адресу `http://127.0.0.1:8080/`.
   При первом запуске автоматически создастся файл базы данных `ads.db`.

## Примеры запросов (через Postman)
1. Регистрация:

   ```json
   POST /register
   {
       "email": "test@mail.ru",
       "password": "securepassword"
   }
   ```
2. Логин (получение JWT-токена):

   ```json
   POST /login
   {
       "email": "test@mail.ru",
       "password": "securepassword"
   }
3. Создание объявления (`Header: Authorization: Bearer <ваш_токен>`):

   ```json
   POST /advertisements
   {
       "title": "Продам гараж",
       "description": "Хороший гараж, сухой"
   }
   ```
